# 判断記録（Decision Log）

各項目は Claude Code が Phase 0 で採用した判断です。「後で変更可能」の欄は、変えたときの影響の大きさを示します。最終的な採否は利用者と ChatGPT が決めます。

| # | 判断 | 理由 | 却下した代替案と理由 | 後で変更可能か |
| --- | --- | --- | --- | --- |
| D1 | 言語は Python。対応範囲は `>=3.11` | 依頼で第一候補とされていた。`tomllib` と `StrEnum` が標準ライブラリにある。作業環境に 3.11/3.12/3.13 があり、3.14 も入手できた | Node.js：数値シミュレーションと LLM SDK のどちらでも Python に劣る利点がない。3.10 対応：`tomllib` が使えない | 容易（下限を上げるのは容易） |
| D2 | 本体は標準ライブラリだけで動かす（`dependencies = []`）。OpenAI SDK は追加機能（extra）とする | 依存が少ないほど再現と監査が容易で、Windows でも詰まりにくい | pydantic で検証：本体には不要。dataclass と手書きの検証で十分 | 容易 |
